## Install

```sh
curl -fsSL https://raw.githubusercontent.com/rune-task-runner/rune/main/scripts/install.sh | sh
```

Or see [every installation method](/rune/installation/) — Homebrew, Docker, `go install`,
or a release archive.

## A Runefile

```rune
# Build the project.
build target="release": fetch
    go build -tags {{target}} ./...

# Fetch dependencies.
fetch:
    @go mod download

# Run tests.
test: build
    go test ./...
```

```sh
rune              # show the version + available tasks (runs nothing)
rune build        # run the `build` task
rune test         # runs `build` (a dependency), then `test`
rune --list       # shows documented tasks
```

## Why Rune

<CardGrid>
  <Card title="A command runner, not a build system" icon="rocket">
    Tasks always run when asked. No `.PHONY` traps, no timestamp guessing. Content-hash
    caching exists as an explicit per-task [`[cache(...)]`](/rune/how-to/caching/) opt-in.
  </Card>
  <Card title="Errors are a feature" icon="warning">
    Undefined variables, unknown dependencies, dependency cycles and arity mismatches are
    caught *before anything runs*, with `file:line:col` and caret-underlined
    [diagnostics](/rune/diagnostics/).
  </Card>
  <Card title="Agents are first-class" icon="puzzle">
    Every task is an MCP tool — read-only by default, gated when destructive. Your agent and
    your terminal run the same definitions. See [AI agents (MCP)](/rune/mcp/).
  </Card>
  <Card title="Polyglot task bodies" icon="seti:python">
    Shell, Python, Node — or an AI agent — as the body of a task, chosen per task with
    [executors](/rune/how-to/executors/).
  </Card>
  <Card title="Composable across a repo" icon="seti:folder">
    Split and namespace task files with [imports and modules](/rune/how-to/imports-and-modules/),
    and run independent prerequisites [in parallel](/rune/how-to/parallelism/).
  </Card>
  <Card title="Secrets stay secret" icon="approve-check">
    Values of sensitive-looking variables are masked as `***` in all output, and are never
    exposed to agents. See [secret masking](/rune/how-to/secret-masking/).
  </Card>
</CardGrid>
